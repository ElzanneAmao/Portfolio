AI-integrated content system design

Your team can use AI for content without everything starting to sound like it was written by the same intern at every company. This is the engagement that puts a proper system in place.

Engagement typeProject (bounded)

The engagement

What this engagement is for

AI can improve your content operation, but getting from "everyone is using it however they see fit" to "we have a system" is hard to do from inside the team while you're also running it. I come in, map how your team works, design the system around the tools you already use, build the prompt systems for each channel, and train the team to run it on their own.

The process

A five-phase build

01 Phase 01

Brand and content audit

I can't design a system for a brand I don't understand. This phase uses findings from a content audit — either one I've done, or one from a previous agency within the last three months. If you haven't had one, we start there.

Phase 02

Operational audit

Mapping the current tools, who creates what content, how approvals work, and where the bottlenecks are. I'm also looking for who owns — or should own — the prompt system once I leave.

Phase 03

System design

Designing the end-to-end workflow from brief to publication. This is the blueprint — documented visually so the team has a single source of truth they can actually refer back to.

Phase 04

Custom AI content system

Building channel-specific prompt systems calibrated to your brand voice, using whatever AI tool your team already works with. Not generic templates — prompts designed around how you actually write.

Phase 05

Handover and training

Team training run from the system documentation itself, so the material and the method are consistent. Separate session for the prompt skill owner on maintenance and iteration.

The deliverable

What you receive

A working content system built for your team and documented so it can outlast the engagement. Specifically:

  • End-to-end documented workflow from brief to publication
  • Prompt skill documents for each content channel
  • Tool integration map showing how AI fits the existing stack
  • Quick reference guide for daily use
  • Change log template so the system can evolve without starting over

Who this is for

Small and medium businesses who have done the diagnostic work — whether through an audit with me or separately — and are ready to build. The ideal client has a clear picture of where the content operation is breaking down and a team that will own the system once it's built.

This engagement follows the AI Content Operations Audit naturally, but it isn't a prerequisite. If you already know what's wrong, we can start here.

All work is done collaboratively with your team, not handed over as a finished artefact. The system only works if the people running it were part of building it.
